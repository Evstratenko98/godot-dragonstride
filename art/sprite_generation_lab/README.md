# Sprite Generation Lab

This folder contains experimental generated art that is not connected to gameplay scenes.

- `knight_warrior_idle_128.png` — final 128×128 RGBA sprite with a transparent background.
- `knight_warrior_idle_alpha_full.png` — full-resolution transparent intermediate.
- `knight_warrior_idle_chroma_source.png` — original generated chroma-key source.

The knight uses dark graphite plate armor, restrained cyan Order accents, a sword, and a shield with an original geometric rune.

The `knight_warrior_walk_forward/` folder contains an experimental eight-frame forward walk cycle derived from the same character anchor.
